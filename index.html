My Projects

A selection of my academic and personal work

IC Checker (Digital & Analog)

A fault-detection system for integrated circuits. The digital version uses Arduino to test ICs automatically, while the analog version relies purely on logic gates. It can identify faulty ICs and recognize their IC numbers.

Arduino Logic Gates Electronics
Github Code

ETE Telepathy

A full-stack social platform for students, alumni, and teachers to connect based on interests and expertise. Built with React, MongoDB, Node.js, and Cloudinary for media management.

React Node.js MongoDB Cloudinary
Live Demo GitHub Code

3-Band Audio Equalizer

A hardware-based 3-band audio equalizer with amplifier and voltage stabilizer. It provides +12V to -12V DC from AC power and independently adjusts bass, mid, and treble frequencies using analog components.
